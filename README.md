# 租房决策助手

一个完全在浏览器中运行的租房对比工具。它不会只比较挂牌月租，而是把真实月成本、首月准备金、通勤、居住体验和租住安全放在一起计算，帮助你更清楚地看见每套房的取舍。

## 主要功能

- 同时比较多套房源，并根据综合评分自动排序
- 计算包含管理费、物业费、水电预估及一次性费用摊销的真实月成本
- 计算签约时需要准备的首月资金
- 支持均衡考虑、预算优先、少点通勤、住得舒服和自定义评分模式
- 根据采光、房屋状态、噪音、面积及楼层电梯评估居住体验
- 核对房东类型、转租授权、押金、水电、退租和维修条款
- 生成结合成本、通勤和安全信息的决策点评
- 支持决策卡和固定表头、固定项目列的对比表

## 隐私说明

房源信息和评分偏好只保存在当前浏览器的 `localStorage` 中，不会上传到服务器。清除浏览器数据会同时清除已保存的房源，请自行保留重要信息。

## 使用方法

这个项目是纯静态网页，不需要安装依赖。

1. 下载或克隆仓库。
2. 直接打开 `index.html`；或在当前目录启动任意静态文件服务器。
3. 添加房源，选择评分模式并调整权重。

## 评分逻辑

```text
综合分 = 经济成本分 × 成本权重
       + 通勤分 × 通勤权重
       + 居住体验分 × 居住权重
       + 租住安全分 × 安全权重
```

- 经济成本分：真实月成本占 72%，首月付款压力占 28%。
- 通勤分：根据单程通勤时间在当前房源中相对换算。
- 居住体验分：采光 28%＋房屋状态 24%＋安静程度 18%＋面积 20%＋楼层电梯 10%。
- 租住安全分：从 100 分开始，每项“待确认”扣 8 分，每项“有问题”扣 20 分。

成本和通勤采用当前房源之间的相对评分，因此增加或删除房源后，排名可能发生变化。
